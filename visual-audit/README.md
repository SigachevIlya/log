# Визуальная проверка 0.5.1

Запускается только в новом временном профиле Chromium. Нативная база `log-diary` в этом профиле изолирована от браузера пользователя; постоянный профиль и реальные результаты не открываются.

## Повторение в PowerShell

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd exec -- playwright install chromium
$env:LOG_PREVIEW = '1'
npm.cmd run test:visual
```

Если Chromium уже установлен, можно вместо установки указать `$env:LOG_BROWSER_EXECUTABLE='C:\полный\путь\chrome.exe'`. Playwright сам запускает production preview на порту 4173 и закрывает принадлежащий ему сервер. При уже работающем preview используется существующий сервер: убедитесь, что он раздаёт актуальный dist, а не dev-сборку.

Источник данных — `tests/helpers/audit-data.ts`, сценарий — `tests/visual-audit.spec.ts`. Фиксированное время 27.11.2026 14:00 Europe/Moscow, 60 тренировок августа–ноября и 16 измерений. Есть рост веса, рост повторов при одинаковом весе, рост за период с последним снижением, четыре сопоставимых выполнения без улучшения, рекорды, неполные/skipped, чередование, стороны и длинное название. Демонстрационные результаты не добавляются обычным запуском приложения.

## Материалы

Перечисленные ниже файлы создаются локальным тестом и исключены из Git. В репозитории сохраняются сценарий и эта инструкция; локальные результаты и диагностические артефакты не публикуются.

- `progress-dark-viewport.png`, `progress-light-viewport.png` — начальная область **375 × 667**, включая основные показатели, вес и начало подробной навигации.
- `progress-{theme}.png` — полный обзор.
- `progress-exercises-{theme}.png` — список упражнений.
- `progress-exercise-incline-press-{theme}.png` — подробности длинного названия.
- `progress-volume-{theme}.png` — нагрузка.
- `progress-records-{theme}.png` — рекорды.
- `progress-recommendations-{theme}.png` — рекомендации.
- `progress-body-{theme}.png` — собственный вес.
- `active-{theme}.png` — дополнительная проверка активной тренировки.
- `metrics.json` — измерения 320/375/390 × 667 в обеих темах, поля, горизонтальная прокрутка и ошибки JavaScript.

Полноразмерные снимки сохраняют fixed-навигацию в положении начального viewport; оценивать начальную область следует по отдельным viewport-снимкам. Автотест также прокручивает страницы до конца и проверяет, что последние элементы доступны над панелью. Для обычных экранов проверяется один h1, для главной — полная видимость кнопки начала при заполненной истории. Дополнительно измеряются программа, библиотека/редактор, история/редактор, настройки, руководство и копии.

Это Chromium на компьютере. Физические iPhone 8/Safari iOS 16, реальная клавиатура и системная установка PWA остаются отдельной проверкой.
